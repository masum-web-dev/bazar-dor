# বাজার দর (BazarDor) 🛒

একটি আধুনিক, রেসপন্সিভ এবং রিয়েল-টাইম মার্কেটপ্লেস ওয়েব অ্যাপ্লিকেশন, যার মাধ্যমে ব্যবহারকারীরা সহজেই নিত্যপ্রয়োজনীয় পণ্যের বর্তমান বাজারদর, দামের পরিবর্তন এবং বিভিন্ন ক্যাটাগরির তুলনা দেখতে পারেন।

## 🚀 Technologies Used (ব্যবহৃত প্রযুক্তি সমূহ)
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth (Email/Password, Google & GitHub OAuth)
- **Database:** MongoDB
- **Notifications:** React Hot Toast
- **Language:** JavaScript / JSX, Bengali (বাংলা)

## ✨ 5 Key Features (প্রজেক্টের ৫টি প্রধান বৈশিষ্ট্য)
1. **রিয়েল-টাইম বাজারদর ও তুলনা:** নিত্যপ্রয়োজনীয় বিভিন্ন পণ্যের আজকের বাজারমূল্য, দাম বৃদ্ধি বা হ্রাসের শতকরা হার সরাসরি ট্র্যাক করার সুবিধা।
2. **নিরাপদ অথেন্টিকেশন সিস্টেম:** Better Auth ব্যবহার করে ইমেইল-পাসওয়ার্ডের পাশাপাশি Google এবং GitHub দিয়ে সহজে সাইন-ইন ও সাইন-আপ করার ব্যবস্থা।
3. **স্মার্ট প্রোডাক্ট সোর্সিং ও ফিল্টারিং:** ক্যাটাগরিভিত্তিক পণ্য ব্রাউজ করা এবং সংখ্যাভিত্তিক (Numeric) ফিল্টার বা সাজানোর অপশন।
4. **বাংলা লোকলাইজেশন ও নোটিফিকেশন:** পুরো ইন্টারফেসে বাংলা ভাষা এবং সফল লগইন বা রেজিস্ট্রেশনে আকর্ষণীয় টোস্ট নোটিফিকেশন।
5. **মডার্ন UI/UX এবং কাস্টম পেজ:** সবুজ থিমভিত্তিক ব্র‍্যান্ডিং, হোমপেজে ইন্ট্রো অ্যানিমেশন এবং সুন্দর একটি কাস্টম 404 নট ফাউন্ড পেজ।
